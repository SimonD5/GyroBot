# Répéteur / Banc d'essai Gyrobot

Ce dossier regroupe le prototype de test (banc d'essai) pour mettre au point l'équilibrage du robot deux roues et tester les liaisons sans fil.

## Contenu :
- `3D/` : pièces du châssis de test modélisées et imprimées en 3D (V1 et V2).
- `Code/` : codes Arduino pour l'ESP32-C6 (tests des moteurs, de la centrale inertielle, asservissement PID et relevage auto) avec les outils python pour régler les gains en wifi.
